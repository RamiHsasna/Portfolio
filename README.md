# Portfolio

This project is a personal portfolio website built to showcase projects, skills, and contact information in a clean, modern layout.

It is built with Astro, React, and Tailwind CSS, with a minimal design focused on performance and readability.

## Features

- Personal portfolio landing page
- Project showcase section
- Contact form area
- Responsive dark-themed design
- Fast static site setup with Astro

## Tech Stack

- Astro
- React
- Tailwind CSS
- TypeScript

## Run locally

```bash
npm install
npm run dev
```

Then open the local preview in your browser.
